# ALÉA Club App

App cliente para ALÉA Aesthetic House.

## Función

Permite que clientas se registren con nombre, teléfono y correo, vean promociones, productos, tips y soliciten citas por WhatsApp.

## Desarrollo

```bash
pnpm install
pnpm run dev
```

Puerto local configurado: `3001`.

## Producción

```bash
pnpm run build
```

La salida se genera en `out/`.

## Integración Futura

Este proyecto debe conectarse después a la misma base de datos que `alea-admin-panel`, idealmente Supabase.
